# การศึกษาปัจจัยที่ส่งผลกระทบต่อมลภาวะของชุมชนริมน้ำจันทบูร

**ประเภทงาน:** รายงานวิจัยกลุ่ม / Group research report  
**วิชา:** ระเบียบวิธีวิจัยธุรกิจ (278411)  
**สถาบัน:** คณะวิทยาศาสตร์และศิลปศาสตร์ สาขาบริหารธุรกิจ มหาวิทยาลัยบูรพา วิทยาเขตจันทบุรี  
**ปีการศึกษา:** 2554 (2011/2012)

เผยแพร่เปิดสาธารณะเพื่อให้คนค้นคว้าเรื่องมลภาวะชุมชนเก่า จันทบูร และสิ่งแวดล้อม

- นางสาวจิราวรรณ ดาทอง (52310625)
- นางสาวณภาภรณ์ โกมินทร์ (52310479)

- นายชาญณรงค์ สีคล้าย (52310567)

## คำสำคัญ

มลภาวะ, ชุมชนริมน้ำจันทบูร, มลพิษทางน้ำ, จันทบุรี, การทิ้งขยะ, พฤติกรรมสิ่งแวดล้อม

## บทคัดย่อ

การวิจัยนี้ศึกษาปัจจัยที่ก่อให้เกิดมลภาวะที่ส่งผลต่อการดำเนินชีวิตของคนในชุมชนริมน้ำจันทบูร และเพื่อหาแนวทางแก้ไขและป้องกัน กลุ่มตัวอย่าง 100 คน สุ่มแบบตามสะดวก วิเคราะห์ด้วย SPSS

**ผลหลัก**
- ผูตอบส่วนใหญ่ร้อยละ 69 อายุ 40 ปีขึ้นไปร้อยละ 37 อาศัยบ้านส่วนตัวเฉลี่ย 22.46 ปี
- สาเหตุหลักอันดับ 1: ทิ้งขยะลงแม่น้ำลำคลอง (ร้อยละ 58.5 ของผูที่จัดอันดับนี้เป็นลำดับ 1)
- ปัญหาที่ควรแก้: มลพิษทางเสียงและทางอากาศ
- ทัศนคติต่อมลภาวะอยู่ในระดับเห็นด้วย ค่าเฉลี่ยรายข้อ 3.63–3.88
- เพศ อาชีพ กับมุมมองที่ทดสอบ ไม่พบความสัมพันธ์อย่างมีนัยสำคัญ
